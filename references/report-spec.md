# 报告结构与撰写规范

## 整体结构（三部分）

```
封面信息（标题 / 公司名 / 生成日期 / 查询日期范围）
├─ 第一部分：概览页
├─ 第二部分：详细章节（1–9）
└─ 附录：资料来源清单
```

## 第一部分：概览页

一页速览，用一张表 + 一段提示语呈现：

| 项目 | 内容 |
| --- | --- |
| 公司名称 / 代码 / 上市地 / 行业 | |
| ESG 报告披露 | 最新一份报告名称与年份、累计披露情况 |
| 最新 ESG 评级 | 分机构逐行列出（含发布日期），不跨机构比较 |
| 治理架构 | 是否设立董事会层面 ESG 委员会 / 工作组，一句话概括 |
| 关键承诺 | 双碳目标等（如有） |
| 重大风险提示 | 处罚、问询、诉讼（负面舆情开启时；无则写「未查到」） |
| 数据完整度说明 | 哪些数据项本次未覆盖、建议人工补充渠道 |

概览页末尾固定两个小节：

**最新 ESG 评级与行业排名**：先用一段话概括总体水平与分化情况（哪几家机构给中高档、哪家明显偏低、是否有时滞），再用表格呈现（机构 / 最新评级 / 日期 / 行业排名）。

数据完整度一行：说明哪些数据项未覆盖、建议人工补充渠道。

固定声明一行：本报告基于公开信息整理，正文上标编号对应附录来源清单。

## 第二部分：详细章节

| 章节 | 内容要求 |
| --- | --- |
| 1 公司概况 | 工商信息、股权结构、上市信息、主营业务、行业地位 |
| 2 ESG 治理架构 | 董事会/委员会/工作组层级与职责表；治理数据（董事会构成、考核绑定）；实质性议题评估结论；查不到写「未披露」 |
| 3 ESG 制度体系 | 制度名称、发布日期、链接的清单表 |
| 4 报告披露情况 | 先写一段总结：累计披露年数、报告名称沿革（CSR→社会责任→可持续发展报告等）、发布时间集中在哪个时段（特殊年份单独说明）、最新报告编制依据；下方列表**默认只列近三年报告**，更早年份用折叠块（`<details>`）收纳，点开可查 |
| 5 ESG 评级对照 | 先写两段总结：①各机构评价总体水平与分化说明（谁给得高、谁给得低、国际与国内机构差异、数据时滞）；②自身表现（较上年变动、行业相对位置）。然后**一张大表**：评级机构 / 近三年评级级别 / 较上年变动 / 行业排名 / 三个同业公司最新评级。不再单独设行业排名、同业对比章节 |
| 6 新闻与奖项 | 近 1–2 年，表格：日期 / 事项 / 来源链接 |
| 7 关键绩效摘要 | 只取报告披露值：指标 / 数值 / 年度 / 来源；禁止自行换算或推算 |
| 8 承诺与目标 | 双碳目标、净零承诺及时间表，注明出处 |
| 9 负面舆情与处罚（开关） | 表格：日期 / 事项 / 类型（环保处罚/安全生产/监管问询/诉讼）/ 来源链接；只记已核实事实，不做定性评价 |
| 10 拜访话题建议 | 基于数据缺口列 3–5 个可切入话题 |

可选模块关闭时跳过对应章节并保持编号连续。

## 附录：资料来源清单

两列表格：编号 / 资料来源。来源标题做成超链接（点击打开原文），括注发布方与日期；**不单列 URL 列，不列查询日期列**；无链接的接口类来源用纯文本描述并注明查询日。

## 撰写规范

- 正文事实性内容一律带上标编号 `[n]`；分析性过渡句可不带。
- 数据缺失统一措辞：「未查到」（检索过但没有）、「未披露」（公司未公开）、「待人工补充」（有建议渠道，如 Wind 终端）。
- 评级表格每行标注机构名与发布日期，禁止写「评级较好/较差」这类跨机构比较。
- 负面舆情章节只陈述已核实事实（谁、何时、什么事、来源），不写主观判断。
- 货币单位随上市地市场；数字保留原始披露精度，不自行约整。

## 样式规范

- **样式确认机制**：首次生成报告前，先用模板加示例数据出 HTML 样张请用户确认；确认后的样式固定复用，调整样式须再次确认。
- **整体版式**：社区首页风格——浅灰页面底色（#f5f6f8）、白色圆角卡片（圆角 12px、细边框）逐节排布、蓝色主色（#2456a6）、无背景图、无花哨装饰；打印时退化为白底。
- **来源上标交互**：正文 `[n]` 上标用 `<sup class="src"><a href="URL" data-tip="来源标题（发布方，日期）">` 实现——悬浮显示资料名单提示、点击打开原文链接。
- HTML：自包含单文件（内联 CSS，无外部依赖）。
- 篇幅导向：结构完整优先，各章节数据有多少写多少，不注水不凑数。
